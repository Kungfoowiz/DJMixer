# 12. Glossary

Terms used across chapters 1-11 that a newcomer to this system might stumble on.

## Terms and abbreviations

- **CircuitPython** — A Python-like language and runtime for microcontrollers; runs the
  firmware on the Raspberry Pi Pico.
- **GPIO** — *General-Purpose Input/Output* — the physical pins on the Pico that read knobs,
  buttons and drive LEDs.
- **MIDI CC** — *MIDI Control Change* — a message type carrying a continuous value (0-127),
  used for the knob and fader.
- **PFL** — *Pre-Fader Listen* — the Mixxx control that routes a channel to the headphones
  without sending it to the main output; what the cue buttons trigger.
